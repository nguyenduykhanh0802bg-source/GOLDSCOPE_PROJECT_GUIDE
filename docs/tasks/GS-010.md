## Phạm vi thay đổi dự kiến

api, services, db predictions/outcomes/deployments, integration tests. Đường dẫn tương lai chưa tồn tại thì chỉ tạo khi task yêu cầu. Kiểm tra source/worktree trước khi chỉnh sửa.

## Các bước thực hiện

Routers/schema/error handlers; read-only endpoints; query filters/paging; model/performance; health/freshness; immutable predictions và versioned outcomes.

## Ngoài phạm vi

Không fetch provider/train trong GET; không public admin routes; không để log/response lộ path/secret.

## Đầu ra

API app/OpenAPI thực tế, fixtures client và integration tests.

## Tiêu chí nghiệm thu

Schema/units/modes/null/error codes khớp API_CONTRACT; static routes không bị dynamic ID bắt nhầm; stale không đổi timestamp; outcome không ghi đè prediction.

## Cách kiểm chứng

PostgreSQL API tests; 404/422/503; pagination/order; synthetic/live isolation; redaction.

## Xử lý blocker

Thiếu credentials/data/environment/contract thì ghi rõ phần đã làm và phần chưa thể kiểm chứng; không thay bằng dữ liệu giả hoặc kết quả ước đoán. Tiếp tục phần độc lập được phép. Trạng thái chỉ chuyển DONE khi các tiêu chí trên có evidence.
